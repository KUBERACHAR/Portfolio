# Portfolio

A personal portfolio website of KUBERACHAR A M, built to showcase education, technical skills, projects, experience, and contact information in a clean and interactive one-page experience.

## Portfolio link
- https://kuberachar.netlify.app/

## Overview

This is a responsive portfolio website designed to present the developer's profile in a polished way. It includes sections for:

- About Me
- Education
- Skills
- Projects
- Experience & Internships
- Interests & Goals
- Contact Details

The website is built using simple web technologies and includes animated interactions such as smooth scrolling, a typing effect, an intro overlay, and project modals.

## Features

- Responsive and modern layout
- Smooth navigation with animated scrolling
- Interactive typing effect for role highlights
- Project cards with detailed modal views
- Contact links for LinkedIn, GitHub, Email, Phone, and Instagram

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome Icons
- Typed.js

## Project Structure

- index.html - Main portfolio page structure
- style.css - Custom styling and layout
- script.js - Interactive behavior and animations
- public/ - Images, icons, and project assets

## How to Run Locally

1. Clone the repository.
2. Open the project folder in your preferred code editor.
3. Open index.html in a browser, or use a live server extension for a better development experience.

No build step is required for this project.
